# Спецификация генератора палеток Jd (для следующего этапа портирования)

Лист «Нормировка Jd ГС по секциям», колонка A генерируется формулой (ячейка A5, протянута вниз):

```
=Get_Jd($ES$1, $EW$1, $FE$1*$FA$1,
        Get_J($GF$1, $FI$1, B5/$GJ$1, B5, $FT$1, $FX$1, 0.07, $CY5,
              $FE$1, 0, $ES$1, $FM$1, $EW$1, 0, 0, 0, 0, 0, 0, 0, 0))
```

## Отображение аргументов (кэш контрольного примера из книги)

| Аргумент | Ячейка | Значение | Смысл |
|---|---|---|---|
| Get_Jd: mu | ES1 | 13.699249282013303 | вязкость, сПз (интерполяция кривой PVT) |
| Get_Jd: B | EW1 | 1.0755417140124952 | объёмный коэффициент |
| Get_Jd: k·h | FE1·FA1 | 26·25 = 650 | мД·м |
| Get_J: i_k_2 | GF1 | 0.1 | kz/kh (анизотропия) |
| Get_J: phi | FI1 | 0.18 | пористость, д.ед. |
| Get_J: l_hor | B5/GJ1 | Lгс/0.7 | длина ГС, приведённая |
| Get_J: l_hor_effective | B5 | 0.05 … 3.7 | эффективная длина (сетка колонки B) |
| Get_J: t_p | FT1 | 60 | время, сут |
| Get_J: r_e | FX1 | 350 | радиус дренирования, м |
| Get_J: r_w | — | 0.07 | радиус скважины, м |
| Get_J: h | CY5 | 1 | эффективная мощность (в палетке =1, нормировка) |
| Get_J: k_h | FE1 | 26 | проницаемость, мД |
| Get_J: s | — | 0 | скин |
| Get_J: mu | ES1 | 13.699… | вязкость |
| Get_J: c_t | FM1 | 1.4315427414884497e-4 | сжимаемость, 1/атм |
| Get_J: B | EW1 | 1.0755… | объёмный коэффициент |
| остальные | — | 0 | без ГРП/МЗС |

Get_J внутри: Boundaryflag=1, BoundaryType=2 (границы постоянного давления),
Wellmodel = горизонтальная скважина, mode=1 (дебит при постоянном забойном).

## Эталоны для проверки (кэш колонки A)

Lгс → L_норм: 0.05 → 0.0024986712438249013; 0.10 → 0.0027318629726130438;
полный набор 55 пар — tests/jd_pallets_fixture.json ("pairs").

## Цепочка зависимостей Get_J (VBA)

- c__Productivity.bas — диспетчер Get_J (~672 строки): опции расчёта, выбор модели;
- d2____Pd_hor_3_1.bas — безразмерное давление горизонтальной скважины;
- d3____HorizFrac_3_1.bas, c4/c5 — трещины/МГРП (для палетки не нужны, аргументы 0);
- u7_Excel_functions / u7_const — константы опций (defCalcOption и др.).

Матрица палетки (ячейки C5:AZ60) уже перенесена в `retools.jd_pallets`
(формула =IF(Lгс>Jd; 1; L_норм_цель/((Jd/Lгс)·L_норм(Lгс))) — проверена на
строках Lгс=0.05 и 0.10 бит-в-бит).


## Статус портирования (обновление)

`retools.jd_generator.get_l_norm` — цепочка перенесена полностью (включая
вербатим-порядок VBA: аспект Батлера по исходной l_hor = Lгс/0.7 ДО подстановки
эффективной длины). Ядро — reservoir_core.horizontal_rect_lapl (путь Calc_Option=1,
точка 0.68 Rosa-Carvalho).

Паритет с колонкой A книги (55 точек): медиана 0,12%, среднее 0,17%, макс 1,88%
(короткая секция Lгс=0,05). Источник остаточного разброса — параметры сходимости
рядов (VBA: tiny=1e-8, MAXIT=100, PART_SUM_NUM=5, sum_num=10000 против
фиксированных лимитов ноутбука). Для бит-в-бит — вербатим-порт
c8____Rectangular_reservoir.bas (pd_lapl_rect с границами c/n, f, F_b1_2/F_b2_2/F_b3_2,
функция Лобачевского sum_num=10000).
