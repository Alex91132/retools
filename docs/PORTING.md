# Статус переноса RE Tools и сверка с книгой

Заметки разработчика: что перенесено из книги RE Tools (Excel/VBA, ~113 тыс. строк в 81 модуле), как сверено,
что найдено в книге. Для работы с программой — [руководство пользователя](USER_GUIDE.md).

## РИГИС: что сделано

| Модуль | Что |
|---|---|
| `retools.rigis` | расчёт по срезам — порт формул листа «РИГИС» (R:CE): петрофизика (Кво/Кно/Квкрит по регрессиям), PVT, ОФП Бейкера, Fw, ПИ секции ГС `Get_J_obsolete` с коэффициентом секции из палеток Jd, депрессия `Get_dP`, Qж/Qн/ГФ, НГЗ/НИЗ. **Сверка с кэшем книги по скважине 4210H: 24 столбца × 219 срезов до 1e-9**, Σ Qн = 648,433 т/сут как в книге. Опция вертикальной скважины (расширение) |
| `retools.rigis_physics` | дословный порт VBA: Get_J_obsolete + Pd ГС (Babu–Odeh) и вертикальной (Чекалюк), Get_dP (Вогель с обводнённостью), ОФП Бейкера, вода (McCain), Get_N, Get_Jd |
| `retools.completion` | **точный подбор компоновки** динамическим программированием вместо «Поиска решения» (эволюционного): мин. длина фильтра, мин. расстояние между фильтрами, число фильтров; предел обводнённости — для каждого фильтра (как в книге) или для скважины в целом (множитель Лагранжа); отступ фильтров от газа; минимальный прирост Qн на фильтр; взаимовлияние секций — итерациями по суммарной длине; **МЗС** — совместный подбор по стволам (общие число фильтров, длина секций, предел по скважине; распределение фильтров между стволами — точно); план изоляции с расстановкой пакеров; раскладка хвостовика; кривая «Qн от предела обводнённости». Подбор ствола — 0,05–0,2 с |
| `retools.rigis_io` | загрузка РИГИС из выгрузки Excel (автоопределение строки заголовков и столбцов по названиям), файл проекта JSON (скважина + объект + палетки) |
| `retools.field_object` | объект разработки (лист PVT_MBE_Waterflood) и палетки секций ГС из книги или проекта |
| `retools.object_builder` | **объект и палетки из параметров, без книги**: таблица матбаланса (порт E3:Y38 + GoalSeek_Np, решается заново построчно) — совпадает с книгой там, где её «Подбор параметра» сошёлся (P ≥ 131 атм, до 1e-9); палетки секций ГС по Get_J_obsolete — бит-в-бит с книгой при её параметрах. Находка: ниже ~124 атм книга хранит несошедшийся матбаланс (невязка до −830), из-за этого Sg и Ct при Рпл 96–110 атм занижены, а дебиты 4210H завышены на ~9 % |
| `retools.forecast` | **прогноз добычи по месяцам** для компоновки на физике срезов: давление — по матбалансу объекта от отбора нефти и воды (вода — в нефтяном эквиваленте), компенсация (закачка/законтурная вода) замещает отобранный объём водой → рост Sw срезов; дренируемый объём — «стадион» 2RL + πR²; **перетоки из изолированных зон**: изолированный коллектор отдаёт в фильтры долю ε своего потенциала, ε растёт с износом эластомеров; остановка по мин. дебиту и предельной обводнённости |
| `retools.lifetime` | **подбор на максимум накопленной нефти или NPV за горизонт**: ценность среза из прогноза (его добыча или денежный поток × (1 − ε) минус цена отбора пластового объёма λ — потеря цели всей скважины на 1 м³ отбора, оценивается прогнозом); то же точное ДП и те же ограничения; итерации «компоновка → прогноз → ценности», возвращается лучшая по полному прогнозу — не хуже подбора на начальный Qн |
| `retools.economics` | стоимость компоновки по раскладке хвостовика (фильтр и глухая труба за метр, пакеры за штуку, постоянная часть) на одном интервале для всех вариантов; денежный поток (нетбэк нефти − подъём жидкости − подготовка воды), NPV с помесячным дисконтированием |
| `retools.report` | выгрузка компоновки в Excel: компоновка, изоляция, срезы, кривая, прогноз (с перетоками), экономика, настройки |
| `retools.ui_rigis` | страница Streamlit: загрузка, настройки, планшет, таблицы, выгрузка |

### Находки в книге

- **«Результат расчёта» устарел**: сводная таблица — кэш прошлого расчёта, с текущими строками «Расчёта добычи»
  не совпадает (январь 2024: 190,6 т/сут в сводной против 980 по строкам). Сверка идёт по строкам листа.
- **НПЗ вытеснения в рейтинге (CJ)**: в строке 7 — от НГЗ вытеснения (CH), в строках 8 и ниже — от CH + CI, хотя
  прирост НПЗ от ППД (CK) расчёт добычи прибавляет ещё раз. По умолчанию — формула строки 7, вариант книги — флагом.
- **Площадь дренирования в НГЗ (CG, CH)**: для трещин «вдоль» и ГС слагаемое 2·Rконт·L учтено дважды
  (формула AF·2·U + U·2·AF). Сохранено как в книге.
- **Get_J для ГС и МГРП плохо обусловлен**: ряд ∫K0 (fast_ik0) у границы x = 18 теряет до 8 цифр, слагаемые
  усиливают это в тысячи раз. Книга сама меняет Get_J на 2e-6 при изменении вязкости на 2 ulp (рейтинг и лист
  расчёта для одной скважины). Побитовое совпадение невозможно, расхождение порта с книгой — до 4e-5.
- **Ошибки VBA, сохранённые для совпадения**: в F_b3_DW_k в pdb3_sub передаётся e_n вместо s; угол бокового
  ствола меняется по ссылке (θ < 0 → θ + 2π); в Get_J угол МЗС — глобальная константа 30°.

Прочее (как было):

1. ✅ `jd.generator` — перенесён (паритет см. таблицу выше). Опционально: вербатим-порт рядов c8 (tiny/MAXIT/PART_SUM_NUM/sum_num) для бит-в-бит совпадения.
2. ✅ `intervals.io` — чтение и агрегация листа РИГИС. Осталось: автофильтры расстановки (колонки U-W), автоподбор кровли/подошвы.
3. ◐ `pvt_mbe`: ✅ матбаланс Хавлена–Оде (MBE_LHS/RHS — бит-в-бит с кэшем книги на 19 давлениях), ОФП Кори + обводнённость + обратная задача Sw(fw), трёхфазная ОФП Бейкера, накопленный ГФ по ОФП. ✅ Корреляции PVT (`retools.cpvt`): Standing/McCain, калибровка на Pb/Rsb/Bob/Muob, паритет бит-в-бит (1e-9, 36 давлений).
| `retools.pallets` | «PVT_MBE_Waterflood» | ✅ палетки заводнения Mu(P×Sw), Kro/Krw Mix(%НПЗ×Sw): чтение из книги + билинейная интерполяция (порт crv_interpolation_2D тип 0), точность в узлах точная |
4. ◐ Профили добычи и рейтинг ГТМ: ✅ ввод-вывод (`retools.gtm_io`: рейтинг ГТМ — 81 колонка входа, результат — месячные ряды) и спецификация шага по месяцам (docs/production_spec.md, эталоны — кэш книги). ✅ Движок `retools.production` — месячный цикл: Рпл из MBE, PI через Kh/mu·Jd, обводнённость из Кори, заводнение через VRR, контроль пределов. Сквозная компоновка cpvt + pvt_mbe + jd, тесты на убывание/рост обв-ти/монотонность кумулятива/эффект ППД.

## Установка и тесты

```bash
pip install -e .[dev]
pip install -e ../reservoir-core   # необязательно: ядро Laplace для jd_generator (тесты без него пропускаются)
pytest
```

## Интерфейс

### CLI

```bash
# профиль добычи по параметрам скважины
python -m retools calc --perm 250 --h 20 --phi 0.18 --sw 0.3 --pres 110 --pwf 50 --months 36

# по скважине из книги RE Tools
python -m retools calc --book RE_Tools.xlsm --well 1 --months 60

# факторный анализ
python -m retools fa --base 200,10,150,80,120 --new 210,0,170,90,110

# PVT-свойства
python -m retools pvt --pressure 110
```

### Streamlit (интерактивное приложение)

```bash
pip install streamlit matplotlib
streamlit run app.py
```

4 вкладки:
- **Профиль добычи** — слайдеры параметров, 4 графика (дебит, обводнённость, Рпл, кумулятив);
- **PVT-свойства** — Rs, Bo, µ, z от давления при настраиваемых параметрах флюида;
- **Факторный анализ** — разложение ΔQн по факторам, интерактивный ввод двух сценариев;
- **Палетки Jd** — тепловые карты нормировки (Mu, Kro/Krw Mix).

## Происхождение и ограничения

Исходник — внутренний рабочий инструмент (VBA),rights у организации.
Числа в тестах — контрольный пример из книги. Публикация кода возможна только
после согласования с организацией и на синтетических данных; демо-данные
в проекте — обезличенные/синтетические.
