# Спецификация движка расчёта добычи (листы «Расчёт добычи» / «Результат расчёта»)

Источник: формулы листа «Расчёт добычи» книги RE Tools 18.08.23
(строка 7, протянута по строкам-скважинам и столбцам-месяцам).
Вход: `retools.gtm_io.read_gtm` (рейтинг ГТМ). Выход: `retools.gtm_io.read_result`.

## Схема листа

- Строки 7+ — скважины; колонки A..CE — INDEX-зеркало рейтинга ГТМ
  (`=INDEX('Рейтинг ГТМ'!$A:$CK, 7+$GT6, COLUMN())` — $GT задаёт порядок).
- Секции правее:
  - AV..BB — контроль/уставки/запасы (Qж по Dp, коэф. успешности Jd,
    коэффициент эксплуатации, длительность, НГЗ, потенциальный КИН, извлекаемые);
  - BC..BF — результаты шага: **Qж** = DJ + FH, **обв-ть** = (1 − Qн/(Bo·Qж))·100,
    **Qн** = max(DL + FJ, минимум AT), **ГФ** = средневзвешенный (DL·DM + FJ·FK)/Qн;
  - BG..CE — «постоянные по коду объекта» (PVT/ОФП/концевые, зеркала листа PVT);
  - CL..CM — **Рпл шага**: интерполяция PVT-таблицы + решение MBE:
    `CM = MBE_LHS(CN,CR,CT,CX,CQ)/(CG*10) + crv_interpolation(E3:E38, ...)` —
    накопленный отбор (в % от НГЗ) переводится в давление через кривую листа
    PVT_MBE_Waterflood (колонки M/N: Np% → Рпл), MBE-части уже портированы;
  - CN/CO — накопленные Qн/Qж шага (+ добыча месяца × коэф. эксплуатации AX);
  - CP/CQ — накопленный газ (Rp = среднее ГФ по накопленному);
  - CR/CT/CX — PVT при Рпл шага (Bo, Bg, Rs) — уже есть в `retools.cpvt`;
  - DJ.. — дебит истощаемой части (через Jd-продуктивность и палетки истощения);
  - FH/FJ.. — заводнение/аквифер (палетки Kro/Krw Mix по %НПЗ, приёмистость,
    компенсация VRR по AR, ограничения AQ/AU).

## Шаг по месяцам (порт)

1. Накопленные отборы (CN/CO) с прошлого шага + добыча месяца.
2. %НПЗ = накопленный Qн / извлекаемые запасы (BB).
3. Рпл: интерполяция по кривой Np%→P листа PVT (crv_interpolation) с MBE-поправкой.
4. PVT при Рпл (`retools.cpvt.CPVT.calc`).
5. Qж истощаемой части через Jd (модули jd/jd_generator) и палетки (pallets).
6. Заводнение: Kro/Krw Mix по (%НПЗ, Sw) → fw; аквифер AS; ограничения.
7. Qн/Qж/обв-ть месяца; контроль пределов (AT минимум дебита, AU обводнённость).
8. Сводка по датам = «Результат расчёта» (суммы Qн/Qж, среднее обв-ти).

## Эталоны

Кэш «Результата расчёта» (помесячные суммы с 2024-01) — контрольная точка
для сквозного прогона портированного движка на скважинах Северного из рейтинга.
